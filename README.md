# Blog: Trabajo sexual en Colombia

Sitio web estático listo para publicar en GitHub Pages.

## Archivos
- `index.html`: contenido del blog.
- `styles.css`: diseño oscuro y responsive.
- `script.js`: menú móvil y buscador interno.
- `assets/`: mapa mental y noticia suministrados para el proyecto.

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido de esta carpeta** (no es necesario subir el ZIP).
3. En el repositorio entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la dirección pública cuando termine el despliegue.

## Nota
El sitio incluye enlaces a fuentes externas. El video embebido requiere conexión a Internet.

# Más allá del estigma — Trabajo sexual en Colombia

## Publicar o actualizar en GitHub Pages
1. Extrae el ZIP. Abre la carpeta `mas_alla_del_estigma`.
2. En el repositorio existente, sube `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `assets` completa. Conserva las rutas y confirma los cambios (Commit changes). No subas la carpeta contenedora como un nivel adicional.
3. Mantén GitHub Pages configurado en la rama `main`, carpeta raíz (`/`).

## Incorporar el podcast
- Exporta la grabación en formato MP3 y nómbrala `podcast.mp3`.
- Abre `assets/audio` en el repositorio, utiliza Add file → Upload files, selecciona el audio y confirma los cambios.
- Una vez publicada la actualización, el reproductor detectará el MP3. El control de prueba local sirve para escuchar un archivo desde tu equipo sin subirlo.
- En el ZIP no se incluye ninguna grabación, porque aún no fue entregada.

## Evidencias y consentimiento
El proyecto incluye los documentos y registros fotográficos facilitados para la práctica. Antes de publicarlos en un repositorio público, confirma que tienes permiso para difundir imágenes de participantes y sus respuestas, la carta y la futura grabación. El análisis de resultados se presenta de manera cualitativa, sin inventar porcentajes ni afirmar que los estudiantes representan a la comunidad de trabajadoras sexuales.

## Contenido integrado
Los textos originales de objetivos, explicación del logo, análisis de resultados, guion y carta se muestran dentro del HTML. Las 4 fotografías de la práctica y las 30 imágenes de tarjetas y respuestas se muestran en galerías, sin enlaces a PDF. Se mantienen los PDF originales como archivos de respaldo en assets/documentos.
